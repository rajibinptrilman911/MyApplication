## Deskripsi
Aplikasi sederhana pemesanan tiket menggunakan Jetpack Compose.

Fitur:
- Menampilkan harga tiket
- Menambah jumlah tiket
- Mengurangi jumlah tiket
- Menghitung total bayar otomatis
- Reset jumlah tiket
